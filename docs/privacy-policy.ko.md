# TripFit 개인정보 처리방침

시행일: 2026-08-10

TripFit(이하 "앱")은 개인정보를 기능 제공에 필요한 범위에서만 처리합니다. 앱은 광고 SDK나 사용자 추적 SDK를 사용하지 않으며 개인정보를 판매하지 않습니다.

## 1. 계정 없이 사용하는 기능

옷장, 코디, 개인 여행, 짐 목록은 계정을 만들지 않고 사용할 수 있습니다. 다음 데이터는 기본적으로 기기 안에 저장됩니다.

- 의류 이름, 카테고리, 색상, 태그, 메모와 사용자가 추가한 사진
- 코디와 개인 여행의 이름, 날짜, 목적지, 메모와 짐 목록
- 언어, 테마, 동기화 등 앱 설정

iCloud 동기화를 사용자가 켜면 선택한 데이터가 Apple CloudKit/iCloud를 통해 본인의 Apple 기기 사이에서 동기화됩니다. 사진 포함 옵션을 켠 경우 의류 사진도 동기화됩니다.

## 2. 공유 여행에서 처리하는 데이터

공유 여행 기능은 선택 사항이며 Apple로 로그인이 필요합니다. 이 기능을 사용할 때 Google Firebase를 통해 다음 데이터를 처리합니다.

- 계정 정보: Firebase 사용자 식별자, Apple 로그인 식별자, Apple이 제공한 경우 표시 이름
- 공유 여행 정보: 방 제목, 목적지, 국가·시간대, 후보 날짜, 확정 날짜와 참여자 식별자
- 일정 조율 정보: 날짜별 가능 여부, 시간대별 상태, 휴가 사용량, 늦은 합류·이른 출발 여부와 메모
- 공동 준비 정보: 짐 항목, 수량, 담당자와 준비 완료 여부
- 공유 룩 정보: 코디 이름, 날짜, 카테고리, 색상, 스타일 태그와 메모
- 초대·보안 정보: 무작위 초대 토큰의 해시, 만료 시각, Firebase 인증 및 App Check 무결성 확인에 필요한 기술 정보

개인 옷장 사진과 기기의 캘린더 일정 내용은 공유 여행 서버로 업로드하지 않습니다.

## 3. 이용 목적

데이터는 다음 목적으로만 사용합니다.

- 옷장, 코디, 여행과 짐 목록 기능 제공
- 사용자가 선택한 iCloud 동기화와 복원
- 초대받은 참여자 사이의 공유 여행 동기화
- 로그인, 부정 사용 방지, 서비스 보안과 장애 대응

광고, 제3자 마케팅 또는 여러 회사의 앱·웹사이트를 넘나드는 추적에 사용하지 않습니다.

## 4. 처리 서비스

- Apple: Sign in with Apple, iCloud/CloudKit, App Store 결제
- Google Firebase: Authentication, Cloud Firestore, App Check, Hosting

각 서비스 제공자는 해당 서비스 운영에 필요한 데이터를 자체 개인정보 처리방침에 따라 처리할 수 있습니다.

## 5. 공유와 공개 범위

공유 여행 데이터는 해당 방에 초대되어 참여한 사용자에게만 표시됩니다. 공개 프로필, 공개 피드, 광고사 또는 데이터 브로커에게 제공하지 않습니다. 초대 링크를 받은 사람은 링크가 만료되거나 취소되기 전까지 참여를 요청할 수 있으므로, 신뢰하는 사람에게만 공유해야 합니다.

## 6. 보관과 삭제

- 로컬 데이터는 사용자가 앱에서 삭제하거나 앱을 제거할 때까지 기기에 남을 수 있습니다.
- iCloud 데이터는 앱 또는 iCloud에서 삭제하기 전까지 보관될 수 있습니다.
- 공유 여행 데이터는 방이 삭제되거나 관련 협업 계정이 삭제될 때까지 보관됩니다.
- 로그아웃은 서버 데이터를 삭제하지 않습니다.

협업 계정은 앱의 **더보기 → 협업 계정 → 협업 계정 삭제**에서 삭제할 수 있습니다. 삭제가 완료되면 Firebase 인증 계정과 해당 사용자의 공유 여행 데이터가 삭제됩니다. 기기의 개인 옷장·코디·개인 여행은 별도로 삭제하지 않는 한 유지됩니다. 자세한 절차는 [협업 계정 삭제 안내](../account-deletion.ko/)를 참고하세요.

## 7. 보안

앱은 Apple 로그인, Firebase 보안 규칙, App Check와 전송 구간 암호화 등 합리적인 보호 조치를 사용합니다. 다만 어떤 저장 또는 전송 방식도 완전한 안전을 보장할 수는 없습니다.

## 8. 아동의 개인정보

TripFit은 만 13세 미만 아동을 대상으로 설계되지 않았으며, 해당 아동의 개인정보를 고의로 수집하지 않습니다.

## 9. 변경

데이터 처리 방식이 달라지면 이 문서와 App Store 개인정보 공개 정보를 갱신합니다. 중요한 변경은 앱 업데이트 또는 이 페이지를 통해 알릴 수 있습니다.
