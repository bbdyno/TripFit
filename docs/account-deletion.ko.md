# TripFit 협업 계정 삭제

## 앱에서 삭제

1. TripFit을 열고 **더보기** 탭을 선택합니다.
2. **협업 계정**을 선택합니다.
3. **협업 계정 삭제**를 선택합니다.
4. 안내를 확인하고 **Firebase 계정만 삭제**를 선택합니다.
5. Apple 재인증이 나타나면 완료합니다.
6. **협업 계정 삭제 완료** 안내를 확인합니다.

삭제하면 Firebase 인증 계정, 공유 여행 참여 정보와 사용자가 소유한 공유 여행 데이터가 삭제됩니다. 개인 옷장·코디·개인 여행과 iCloud 데이터는 자동으로 삭제되지 않습니다. Apple 구독도 별도로 취소해야 합니다.

앱에서 삭제를 완료할 수 없다면 [지원 이슈](https://github.com/bbdyno/TripFit/issues/new)를 작성해 주세요. 공개 이슈에는 Apple 계정이나 초대 링크를 적지 마세요.
