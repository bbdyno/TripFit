# TripFit 한국어 지원

## 빠른 도움말

1. 앱을 최신 버전으로 업데이트합니다.
2. 앱을 완전히 종료한 뒤 다시 실행합니다.
3. 공유 여행 문제라면 네트워크 연결과 **더보기 → 협업 계정**의 로그인 상태를 확인합니다.
4. iCloud 동기화 문제라면 기기의 iCloud 로그인, 저장 공간과 TripFit의 동기화 설정을 확인합니다.

## 데이터와 계정

- 옷장·코디·개인 여행은 협업 계정과 별도로 기기에 저장됩니다.
- 협업 계정 삭제: [단계별 안내](../account-deletion.ko/)
- 개인정보 처리: [개인정보 처리방침](../privacy-policy.ko/)
- 구독 관리: iPhone **설정 → Apple 계정 → 구독**

## 문의하기

[GitHub Issues](https://github.com/bbdyno/TripFit/issues/new)에서 앱 버전, iOS 버전, 재현 단계와 화면을 남겨 주세요. 공개 이슈에 초대 링크, Apple 계정 정보 또는 개인 여행 내용을 올리지 마세요.
